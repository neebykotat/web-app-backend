# FluffyHost - Backend

Автоматизированная веб-платформа индивидуальной передержки домашних животных «FluffyHost» на основе услуг догситтеров.

## Технологический стек
* **Python 3.13+**
* **FastAPI** — современный веб-фреймворк для создания API
* **Uvicorn** — ASGI веб-сервер
* **SQLAlchemy** — ORM для работы с базами данных
* **Alembic** — инструмент для управления миграциями
* **Pydantic** — валидация данных и работа со схемами
* **Pytest & HTTPX** — инструменты для написания асинхронных интеграционных автотестов

## Инструкция по развертыванию и запуску

### 1. Клонирование репозитория
Склонируйте проект с удаленного репозитория и перейдите в корневую директорию:
```bash
git clone https://github.com
cd web-app-backend
```

### 2. Настройка виртуального окружения
Создайте изолированное виртуальное окружение для зависимостей проекта и активируйте его:

* **Для Windows:**
  ```bash
  python -m venv .venv
  .venv\Scripts\activate
  ```
* **Для Linux / macOS:**
  ```bash
  python -m venv .venv
  source .venv/bin/activate
  ```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой директории проекта и укажите доступы к вашей локальной СУБД PostgreSQL:
```env
DB_USER=postgres
DB_PASSWORD=ваш_пароль_от_postgres
DB_HOST=localhost
DB_PORT=5432
DB_NAME=fluffyhost_db
```

### 4. Установка зависимостей
Установите все необходимые пакеты, зафиксированные в конфигурационном файле:
```bash
pip install -r requirements.txt
```

### 5. Применение миграций базы данных
Перед запуском сервера примените миграции для создания актуальной структуры таблиц в PostgreSQL:
```bash
alembic upgrade head
```

### 6. Запуск сервера разработки
Запустите локальный сервер приложений с помощью Uvicorn в режиме автоматической перезагрузки кода:
```bash
uvicorn app.main:app --reload
```

## Документация API и примеры запросов

### 1. Создание новой записи (POST)
* **Эндпоинт:** `POST /pets/`
* **Описание:** Создает нового питомца в базе данных и привязывает его к системному владельцу.
* **Пример тела запроса (JSON):**
```json
{
  "name": "Рекс",
  "type": "Собака",
  "breed": "Немецкая овчарка",
  "age": 3,
  "description": "Знает базовые команды, дружелюбный"
}
```
* **Пример успешного ответа (201 Created):**
```json
{
  "id": 1,
  "owner_id": 1,
  "name": "Рекс",
  "type": "Собака",
  "breed": "Немецкая овчарка",
  "age": 3,
  "description": "Знает базовые команды, дружелюбный"
}
```

### 2. Получение списка с фильтрацией и поиском (GET)
* **Эндпоинт:** `GET /pets/`
* **Описание:** Возвращает список питомцев с поддержкой пагинации, поиска по имени и фильтрации по типу животного.
* **Параметры запроса:**
  * `skip` — сколько записей пропустить (по умолчанию: 0)
  * `limit` — сколько записей вернуть (по умолчанию: 10)
  * `search` — поиск по подстроке имени (использует `.contains()`)
  * `pet_type` — точная фильтрация по типу (например: `Собака`, `Кошка`)
* **Пример запроса:** `GET /pets/?search=Рекс&pet_type=Собака&skip=0&limit=5`

### 3. Получение питомца по ID и обработка ошибок (GET)
* **Эндпоинт:** `GET /pets/{pet_id}`
* **Описание:** Возвращает данные конкретного животного по его идентификатору.
* **Пример ответа при ошибке валидации (422 Unprocessable Entity):** возвращается автоматически, если вместо ID передана строка (например, `/pets/fluffy-dog`).
* **Пример ответа при отсутствии записи (404 Not Found):**
```json
{
  "detail": "Pet with id 99999 not found"
}
```
