# FluffyHost - Backend

Автоматизированная веб-платформа индивидуальной передержки домашних животных «FluffyHost» на основе услуг догситтеров.

## Технологический стек
* **Python 3.13+**
* **FastAPI** — современный веб-фреймворк для создания API
* **Uvicorn** — ASGI веб-сервер
* **SQLAlchemy** — ORM для работы с базами данных
* **Alembic** — инструмент для управления миграциями
* **Pydantic** — валидация данных и работа со схемами

## Инструкция по развертыванию и запуску

### 1. Клонирование репозитория
Склонируйте проект с удаленного репозитория и перейдите в корневую директорию:
```bash
git clone https://github.com
cd web-app-backend
```

### 2. Настройка виртуального окружения
Создайте изолированное виртуальное окружение для зависимостей проекта и активируйте его:

* **Для Windows:**
  ```bash
  python -m venv .venv
  .venv\Scripts\activate
  ```
* **Для Linux / macOS:**
  ```bash
  python -m venv .venv
  source .venv/bin/activate
  ```

### 3. Установка зависимостей
Установите все необходимые пакеты, зафиксированные в конфигурационном файле:
```bash
pip install -r requirements.txt
```

### 4. Запуск сервера разработки
Запустите локальный сервер приложений с помощью Uvicorn в режиме автоматической перезагрузки кода:
```bash
uvicorn app.main:app --reload
```
